# Detailed Map 1 showcase

Run `../watch.sh` from this folder, or `./mods/graveyard-shift/playtests/watch.sh`
from the repository root. Default viewing uses modern mode at 1920×1080.
The pinned WAD matches this recording; the original IWAD remains at the repository root.

`attempt-07-detailed/session.lmp` is a standard v1.9 demo, HMP, 2:38.40,
36/36 kills and 3/3 secrets. Numeric controls use running, angular acceleration,
and aiming assistance, without cheats. This does not measure human difficulty.
Each control checkpoint has a PNG and JSON state; `commands.jsonl` records inputs.
The carousel tour begins after the last monster dies at 2:17.20.

`verification/` retains GD-DOOM replay and independent Chocolate Doom results, including a complete rendered replay.
`wad-sha256.txt` identifies this geometry and music version.
